# Digital Detox Score Analyzer

A simple Streamlit web app that calculates a "Digital Detox Score" out of 100 based on
daily habits (screen time, social media usage, sleep, exercise, water intake) and gives
personalized suggestions to improve lifestyle.

## How to Run

1. Install requirements:
   pip install -r requirements.txt

2. Run the app:
   streamlit run app.py

3. The app will open in your browser (usually at http://localhost:8501).

## Inputs
- Name
- Daily Screen Time (hours)
- Social Media Usage (hours)
- Sleep Duration (hours)
- Exercise (minutes)
- Water Intake (litres)

## Output
- Digital Detox Score (out of 100)
- Lifestyle Rating (Excellent / Good / Average / Poor / Needs Improvement)
- Personalized suggestions
- General healthy habit tips
